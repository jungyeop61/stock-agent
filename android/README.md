# 주식아 Android · 인증된 전체 에이전트 MOCK 음성 연동 (0.3.0)

Kotlin 네이티브 앱입니다. 빅스비 없이 폰 내부의 Vosk 한국어 오프라인 인식기로
`주식아` / `주식 아`를 감지하고, 호출 후에만 Python 에이전트로 **음성 인식 텍스트**를 보냅니다.
조회·매수/매도·취소/정정·조건주문·실행 복구와 다중 턴 입력은 기존 에이전트에 위임합니다.
새 `/api/agent/sessions/{session_id}/voice-messages` API를 사용하므로 Python 서버도 업데이트해야 합니다.
STT와 TTS는 이 버전에서 기기 내 엔진을 사용합니다. OpenAI 음성 API 연결은 아직 없습니다.
호출 대기 자체로 유료 API를 호출하지 않습니다. 서버의 명령 해석기를 `openai`로 바꾸면
호출 이후 명령 해석에는 해당 API 비용이 발생할 수 있습니다.

## 이번 구현 범위

- 앱에서 명시적으로 대기를 켠 뒤 마이크 foreground service와 상시 알림으로 유지합니다.
- 화면 잠금 중 처리를 위해 service 수명 동안 partial wake lock을 사용합니다.
- 호출 전 인식 결과는 호출어 판별 후 버리고, HTTP 요청·녹음 파일 저장은 하지 않습니다.
- `주식아` → `네, 말씀하세요` → `삼성전자 현재가 알려줘` → 응답 읽기.
- `주식아 삼성전자 현재가 알려줘`처럼 한 문장으로도 요청할 수 있습니다.
- 응답 중에는 마이크 입력을 인식기에 넣지 않으며, 음성 출력이 끝난 뒤 듣기를 재개합니다.
- `그만` / `종료해` 또는 30초 명령 무응답: 대화를 끝내고 호출어 대기로 복귀합니다.
- `대기 기능 꺼줘` / `마이크 꺼줘`: 마이크 service까지 종료합니다.
  대기 상태에서는 `주식아 대기 기능 꺼줘`로 호출과 종료를 한 번에 할 수 있습니다.
- 앱 버튼이나 알림의 `마이크 대기 끄기`로도 완전히 종료할 수 있습니다.
- 조회/후속 답변/미리보기/승인은 한 대화의 UUID를 유지하고, 종료/오류 뒤에는 새 세션을 사용합니다.
- 주문 안내를 **끝까지** 읽은 뒤에만 `승인` 입력을 받습니다. `네/예/응/사/주문해`는 승인으로 사용하지 않습니다.
- 승인/중단은 앱이 안내한 미리보기 ID에 묶어 보내며, 서버도 일치 여부와 승인 대기 상태를 검사합니다.
- 미리보기의 서버 만료 시각과 수신 후 최대 2분 중 먼저 도달하는 시점을 승인 제한으로 사용합니다.
  복구 요청도 앱에서 최대 2분만 승인받습니다. 무응답은 30초 후 미승인 대화를 중단합니다.
- 긴 결과/미리보기는 TTS 제한에 맞춰 여러 조각으로 읽고, 마지막 조각 완료 전에는 듣지 않습니다.
- 서버 POST 자동 재시도 없음. 요청 처리 중에는 추가 입력을 받지 않습니다.
- 통신/응답 오류 후에는 예전 대화를 재개하지 않으며 주문 내역/실행 상태 확인을 안내합니다.
- 각 음성 요청 전 서버에서 Spring의 MOCK, LIVE 비활성화, kill switch 활성화를 확인합니다.
- `그만`/음성 대기 끄기는 가능한 경우 입력 중인 요청 또는 미승인 미리보기만 중단합니다.
  이미 접수된 주문은 취소하지 않습니다. 앱/알림 끄기·강제 종료는 즉시 세션을 버리며 서버 중단을 보장하지 않습니다.

## 지원 명령 예시

```text
삼성전자 현재가 알려줘
내 보유 주식 알려줘
원화 주문 가능 금액 알려줘
내 주식 수수료 알려줘
삼성전자 매도 가능 수량 알려줘
지금 달러 환율 알려줘
100달러는 원화로 얼마야
전체 주문 내역 알려줘
주문번호 order-123 상태 알려줘
조건주문번호 conditional-123 상세 알려줘
실행번호 execution-123 상태 알려줘
삼성전자 5주 사줘
애플 200달러어치 사줘
주문번호 order-123 취소해줘
주문번호 order-123을 7주 71,000원으로 정정해줘
조건주문번호 conditional-123 취소해줘
실행번호 execution-123 복구해줘
```

SINGLE/OCO/OTO 생성과 전체 구성 정정은 Python README의 같은 명령 형식을 사용합니다.
종목/수량/가격 등이 빠지면 같은 세션에서 차례로 답합니다. 주문번호/조건주문번호/실행번호는
조회 결과의 정확한 값을 지정해야 합니다. 음성 번호 선택이나 `첫 번째 주문 취소` 등의 별칭은
추가하지 않았으며, 앱이 임의의 주문을 선택하지 않습니다. 실제 달러↔원화 환전은 지원하지 않습니다.
오프라인 인식기의 숫자·영문 ID·긴 조건주문 발화 정확도는 실기기 검증이 필요합니다.

**전용으로 학습된 저전력 wake-word 모델이 아니라 전체 한국어 STT로 호출어를 판별하는
첫 검증 버전입니다.** 단어 인식 실패·오호출, 배터리 소모, S22의 잠금/절전 정책은 실제
기기 검증이 필요합니다. 인식 정확도나 24시간 무중단 동작을 보장하지 않습니다.
주변 사람/TV가 호출어를 말해도 활성화될 수 있으며 화자 인증이 아닙니다.

## 빌드

Android Studio에서 이 디렉터리를 열고 Android SDK 35 / Build Tools 35.0.0을 설치합니다.
Gradle 8.11.1, JDK 17 또는 21을 사용합니다. 시스템 Java 25/26을 그대로 쓰지 마세요.

```bash
cd android
./gradlew testDebugUnitTest lintDebug assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.
플레이스토어 등록 없이 개발용 APK로 설치할 수 있습니다.
0.1.0/0.2.0 APK가 이미 설치되어 있다면 같은 서명의 0.3.0 APK로 업데이트할 수 있습니다.
기존에 공유한 Drive APK는 자동 갱신되지 않습니다.

로컬 자동 검증:

```bash
python-agent/.venv/bin/python devtools/run_agent_process_e2e.py --voice
```

위 명령은 저장소 루트에서 실행하며 실제 음성 API → Python → Spring → 읽기 전용 토스 스텁의
26개 시나리오를 검사합니다. 마이크/TTS/S22 테스트를 대신하지는 않습니다.

## S22와 로컬 서버 연결

먼저 기존 문서대로 Spring을 MOCK으로 실행하고 Python 에이전트를 실행합니다.
음성 API는 `JUSIKA_BROKER_MODE=mock`, `JUSIKA_LIVE_TRADING_ENABLED=false`,
`JUSIKA_TRADING_KILL_SWITCH_ACTIVE=true`가 아니거나 안전 상태를 읽지 못하면 요청을 차단합니다.
최초 테스트에서는 `JUSIKA_AGENT_COMMAND_INTERPRETER=rules`를 사용하면 외부 AI 비용도 없습니다.
계좌/주문 권한 키와 OpenAI 키는 서버에만 두고 앱에 넣지 않습니다.

S22에서 개발자 옵션과 USB 디버깅을 켜고 맥에 연결한 뒤:

```bash
adb devices
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb reverse tcp:8000 tcp:8000
```

1. 앱을 열고 서버 주소 `http://127.0.0.1:8000`을 확인합니다.
2. `한국어 인식 모델 다운로드`를 누릅니다. 공식 배포처에서 약 82 MB ZIP을 받으며,
   압축 해제 후 공간도 필요합니다. Wi-Fi에서 앱을 열린 상태로 두고 기다립니다.
   모델은 앱 내부 저장소에만 설치되며 Git/APK에는 포함하지 않습니다.
3. `호출 대기 켜기`를 누르고 마이크·알림 권한을 허용합니다.
   오프라인 한국어 TTS 음성이 없으면 휴대폰의 글자 읽어주기 설정에서 한국어 음성을 설치합니다.
4. `호출 대기를 켰습니다` 안내를 들은 뒤 `주식아`라고 부릅니다.
5. `네, 말씀하세요` 뒤에 `삼성전자 현재가 알려줘`를 말합니다.

Python의 기본 바인딩은 `127.0.0.1` 그대로 사용할 수 있습니다. USB reverse가 실제 폰을
맥의 로컬 서버에 연결하므로 LAN 공개나 FastAPI 바인딩 변경이 필요 없습니다.
USB 연결이 끊기거나 휴대폰을 재연결하면 reverse 설정을 다시 확인해야 합니다.
에뮬레이터에서는 `http://10.0.2.2:8000`도 사용할 수 있습니다.

HTTP는 debug 빌드의 loopback/에뮬레이터 주소에만 허용합니다. Release에서는 HTTPS만
허용합니다. 0.3.0에서는 관리자 발급 개인 토큰을 `Authorization: Bearer`로 보냅니다.
서버 설정은 `python-agent/README.md`의 가족용 모바일 인증을 참고하세요. 토큰은 Android
Keystore AES-GCM으로 암호화하고 서버 주소에 묶어 저장합니다. 화면/백업에는 저장하지 않습니다.
서버 주소 변경 시 새 토큰을 입력해야 합니다. 빈칸은 기존 토큰 유지이며, 삭제 버튼은 마이크를
끄고 이 기기의 토큰을 제거합니다. 서버 토큰 폐기는 관리자가 설정을 바꾸고 재시작해야 합니다.
토큰은 OpenAI/증권사 키가 아닙니다. 외부 주소는 개인 토큰 필수, 로컬 USB 개발은 선택입니다.
이 앱은 여전히 MOCK 개발용입니다. 서버 HTTPS 배포·proxy 설정·실기기 Keystore 검증은 별도입니다.

## 실제 기기 수동 검증 체크리스트

- [ ] 호출하지 않고 현재가/주문 문장을 말하면 서버 요청이 발생하지 않는다.
- [ ] 가까이/멀리에서 `주식아`를 불렀을 때 안내가 나온다. 실제 성공률을 기록한다.
- [ ] 응답의 `주식아` 문구가 자기 자신을 다시 호출하지 않는다.
- [ ] 현재가 응답을 읽고 다음 조회를 받을 수 있다.
- [ ] `사줘 → 삼성전자 → 5주` 다중 턴 입력 뒤 미리보기를 읽는다.
- [ ] 미리보기 안내 중 `승인` 발화는 무시되고 끝까지 읽은 뒤에만 승인을 받는다.
- [ ] `네/응`은 실행하지 않고 `승인/취소`를 다시 요청한다.
- [ ] 승인 대기 중 다른 주문을 말해도 원래 미리보기를 바꾸지 않는다.
- [ ] 승인 후 결과가 MOCK이고, 같은 승인이 중복 실행되지 않는다.
- [ ] 승인 만료/무응답/통신 실패 후 예전 요청을 다시 승인하지 않는다.
- [ ] `그만` 뒤 호출하면 다시 대화가 시작된다.
- [ ] 30초 무응답 뒤 호출어 대기로 돌아간다.
- [ ] `대기 기능 꺼줘` 뒤 마이크 사용 표시/대기 알림이 사라진다.
- [ ] 알림의 끄기 버튼과 앱의 끄기 버튼도 마이크를 해제한다.
- [ ] 서버가 꺼져 있으면 실패 안내만 하고 요청을 자동 재전송하지 않는다.
- [ ] 화면 잠금 5분/30분, 절전 모드, 전화 수신 전후 동작을 확인한다.
- [ ] 한국어 TTS 미설치/마이크 권한 거절 시 안전하게 종료한다.
- [ ] 재부팅·앱 강제 종료 후에는 자동으로 마이크를 켜지 않고 재설정을 요구한다.
- [ ] TalkBack으로 설정 버튼과 안내를 확인하고 배터리 소모를 기록한다.
- [ ] 토큰 입력·재시작 후 인증이 유지되고, 틀린/폐기 토큰으로는 조회와 승인이 실행되지 않는다.
- [ ] 토큰 삭제 후 대기가 종료되고, 서버 주소를 바꾸면 이전 토큰을 자동 전송하지 않는다.

최초 설정·재부팅 후 재활성화는 보호자가 도와줄 수 있습니다. 알림 권한을 거절하면
일반 알림창의 중지 버튼을 쓸 수 없으므로 알림 권한을 허용하는 것을 권장합니다.
배터리 설정 변경은 실제 테스트에서 대기가 중단될 때에만 기기 설정을 확인하세요.
